## 曲率标定

按上一版弯道公式 `v=0.36/sqrt(k)`，1.8m/s对应等效曲率
`k_ref=(0.36/1.8)^2=0.04 1/m`、等效半径25m。
这是以原曲率限速为主导约束时的标定推算，不是从实测轨迹测得的半径；
90度转角本身不能唯一决定曲率。左右转弯和180度掉头仍按同一绝对曲率限速。
本轮1.0m/s目标替代较早“相对0.3系数提高20%”的要求。

`ForwardCurveLimitSpeed()` 保留上一版基础曲线，再乘一个平滑下降的倍率：

```text
k = max(前6m几何曲率峰值, 最近30次峰值均值)     k单位：1/m
t = clamp((k - 0.005) / 0.015, 0, 1)
v_old = (0.6 - 0.24*t²*(3 - 2*t)) / max(sqrt(k), 0.001)
u = clamp((k - 0.01) / 0.03, 0, 1)
q = u³*(10 - 15*u + 6*u²)
v_new = v_old * (1 - 4/9*q)                     速度单位：m/s
```

- `k<=0.01`完整保留上一版；区间最低曲率上限为5.377778m/s，可容纳5m/s规划给定。
- `0.01<k<0.04`用五次函数平滑降低倍率；曲率增大时限速单调下降，无过渡反弹。
- `k>=0.04`使用原弯道上限的5/9，即 `v=0.2/sqrt(k)`；参考点恰好1.0m/s，更急的弯更慢。
- 新倍率在0.01、0.04两端的一阶、二阶导数为0，原曲线与新增过渡连接处的一阶导数连续。
  原0.005、0.02基础曲线采用三次过渡，不声称整条曲线二阶处处连续。
- 保留沿线前后各2m的独立三点圆曲率、6m预瞄、30次历史释放与当前车速+0.5m/s。
  没有新增入弯时间滤波、起步斜坡或固定5m/s硬上限。直线最终给定仍由规划等原约束取小。
  6m限定曲率点位置，曲率估计的几何支撑可能读取至约8m处。

## 积分门控与补刹力度

现有代码的积分只负责允许补刹，力度另由速度误差乘系数决定；不存在直接输出刹车的PID积分项。
针对“刹车过猛”，本轮将积分介入后的力度系数从50改为15，即原来的30%；
积分累计仍为 `I += dec*dt`，不再额外推迟介入。`dec=导航实际车速-speed_cmd`，单位m/s，
其中speed_cmd已经经过曲率/故障等限速，但这些限速不能自行建立普通补刹请求。

```text
有效减速请求内：I = min(2*T, I + dec*dt)
T默认0.1m；严格超过T时允许补刹
普通补刹百分比 = round(dec*15)，最低1%、最高100%
```

**默认积分饱和上限为0.2m，即2倍门槛。** 门槛由
`/robot/control/brake_integral_threshold`实时读取；合法值为(0,10]m，非法值回退0.1m。
当前工程参数文件没有设置此键；本机未读取车端ROS参数，不能声称车端运行值必为默认值。
若运行门槛改为0.2m，积分上限相应为0.4m。可用 `rosparam get /robot/control/brake_integral_threshold` 核对。

这里的m来自(m/s)×s，是累计速度误差的量纲，不代表停车距离、剩余距离或刹车百分比。
例如0.5m/s正误差累计0.4秒到0.2m后封顶；允许补刹以后，力度随当前误差变化，
不由“积分恰好等于0.2m”换算出一个固定百分比。

| 当前正速度误差 m/s | 原普通补刹 % | 新普通补刹 % |
|---:|---:|---:|
| 0.2 | 10 | 3 |
| 0.5 | 25 | 8 |
| 0.6 | 30 | 9 |
| 1.0 | 50 | 15 |
| 1.2 | 60 | 18 |
| 2.0 | 100 | 30 |

系数为原30%，整数取整/1%保底/100%限幅后的输出不保证处处恰好为原输出30%。
规划desireSpeed下降建立请求，同值可延续；目标回升、实际速度达到规划目标等原入口清零。
无下降沿的单纯超速、曲率波动与缓停限速不触发普通积分补刹。
原独立急停/围栏/偏差/终点等制动保留优先级，R挡行为、D×13.5与5/13.5保底保持。

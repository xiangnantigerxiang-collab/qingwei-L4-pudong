## 当前规则

入口：`control_comply.cpp::ForwardCurveLimitSpeed()`。

```cpp
const double preview_distance = std::max(0.0, double(mVehicleSpeed)) * 4.0;
```

`mVehicleSpeed`由`/navigation_msg.gpsSpeed`更新，单位m/s；4.0是秒，结果为米。
使用当前导航速度，不使用规划desireSpeed、CAN车速或已经被曲率限制后的速度给定。

| 当前导航车速 m/s | 预瞄距离 m |
|---:|---:|
| 0 | 0 |
| 0.5 | 2 |
| 1 | 4 |
| 1.5 | 6 |
| 3 | 12 |
| 4.5 | 18 |
| 5 | 20 |

- 不设置6m下限，也不额外加入距离上限；现有轨迹不够长时只取到真实末点，不外推/补零。
- 从导航参考点在路径上的投影起，按沿线路程取最大绝对曲率；保留起点/边界插值和重复点处理。
- 零速仍取当前投影曲率，保留历史释放规则；负速度按0m。非有限速度沿用主流程100%安全制动，
  限速函数自身也返回0并清除曲率历史，避免独立调用时将NaN解释为零速。
- 仅导航速度变化即可在当前控制周期改变预瞄范围，不需要等待新的规划消息。

## 保持的算法与变化边界

曲率到速度的公式完全不变：k<=0.01保持直线/细微波动区间，k>=0.04仍为0.28/sqrt(k)，
等效参考k=0.04时上限1.4m/s，过渡区仍为原五次倍率。转弯角度本身不决定固定速度。

几何曲率仍由前后各2m三点圆计算，路径更新/进入D时重建独立缓存；原横向曲率保持。
预瞄距离只限定被选曲率点的位置，估计支撑通常可延至L+2m，端部仍平移完整4m几何窗口。
因此零速也保留当前位置的平滑几何曲率，不能理解成不读取任何前方坐标。

仍取当前峰值与最近30次峰值均值的较大值：新入窗急弯当周期约束；窗口缩小时不额外清空历史，
连续30次不含弯道的观测后旧弯道影响才完全消失。未增加新的时间滤波、缓存或速度上升斜坡。
窗口扩大后可能选到更远的弯道，限速和历史数值可以变化；保持的是估计和历史算法，不是逐帧数值。

当前车速+0.5、D×13.5/5%保底、普通补刹15及规划desireSpeed下降触发、默认积分上限0.2m、
独立安全停车、横向/R与planning均保持。4秒行程不代表机械制动必定能在该范围内完成。

## 开销与交付

设N为完整路径点数、P为动态窗口中扫描点数，周期仍O(P+30)，最坏O(N+30)；
路径更新的几何缓存仍O(N)，没有因车速变化重建。新增常数次车速计算/校验，较高车速需要扫描更多点；
约0.1m采样时，5m/s对应约200个线段，原6m约60个线段。实例及缓存布局不变，额外空间O(1)。

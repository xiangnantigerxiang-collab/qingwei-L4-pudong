## 修改与公式

`control_comply.cpp::ForwardCurveLimitSpeed()` 中：

```cpp
const double turn_speed_ratio = 1.4 / 1.8;
```

保留原基础曲线 `v_base`（参考弯道1.8m/s版本）、原五次过渡及其所有阈值：

```text
k = max(前6m几何曲率峰值, 最近30次峰值均值)
t = clamp((k - 0.005) / 0.015, 0, 1)
v_base = (0.6 - 0.24*t²*(3-2*t)) / max(sqrt(k), 0.001)
u = clamp((k - 0.01) / 0.03, 0, 1)
q = u³*(10 - 15*u + 6*u²)

1.0m/s版：v_low = v_base * (1 - 4/9*q)
本轮折中：v_mid = v_base * (1 - 2/9*q) = (v_low + v_base)/2
```

速度单位m/s，曲率单位1/m。由此可直接确认：

- 每个曲率点的上限都处于两版之间，过渡区同样取中值，而非只调整一个参考点。
- k<=0.01时q=0，三版结果完全相同；直线保护区最低公式上限仍5.377778m/s。
- k>=0.04时上限为 `0.28/sqrt(k)`；参考等效k=0.04、R=25m时为1.4m/s。
- 原过渡端点及连续性保持，限速仍随曲率单调下降，无新增时间滤波、迟滞或加速斜坡。
- 半径和曲率决定上限，90度左右转弯、180度掉头角度本身不决定固定车速。
  25m仍是按更早0.36/1.8公式推算的等效参考半径，不是新增实测几何结论。

## 保留的响应策略

与修改前源码对照，除上述倍率及同一行注释外，control_comply.cpp逐字节相同：

- D纵向曲率仍按沿线前后各2m三点圆计算，路径更新/进入D时重建独立缓存。
- 仍从导航参考点的路径投影向前沿线6m取最大绝对曲率；曲率估计支撑可达约8m坐标。
- 仍与最近30次峰值均值取大；新急弯当周期约束，历史只延缓出弯释放，复位入口保持。
- 曲率波动不自行发起普通积分补刹；补刹系数仍15、默认积分门槛0.1m/上限0.2m。
- 当前车速+0.5、D×13.5/5%保底、独立安全停车、横向和R控制保持。

弯道上限被有意提高，所以同一弯道扰动输入的速度数值也会提高；保留的是曲率估计、
预瞄、历史、复位和限速响应时机，不将“策略保持”误写成所有弯道指令数值不变。

## 生产行为

### 旧周期、新请求和跨挡执行记忆

- 已确认释放的旧周期先结束，即使本周期需要发布新的停车请求，也不能复用旧`zeroSince`判新请求失败。
- 每次新的正请求或普通转强停车，独立建立响应时窗。请求前的正反馈和同一接收时刻的重复回调不能确认新请求。
  任何非零实际反馈仍立即参与D禁油；这种时序确认不等同底盘指令序号ACK。
- 自动N/R发布的最终制动量只登记到执行记忆，控制字段、发布数量/顺序不改；切D继续处理在途请求。
  R原有1～5%的小补刹保留普通类别，不因切D而误归为强停车；D接管后仍明显减速不足时仍可故障保护。
  人工模式下软件发出的停车量不登记为已执行。规划、任务、换挡复位不能清物理执行记忆。
- 最早尚未确认的强请求另行计时，反复撤销/重发不能推迟其2秒无响应判定。
- 未接入液压时遇时钟回退，重建观察、积分、差分时基，保留有效规划下降请求；已有在途液压仍按异常保护。

### 普通液压介入

保留原始`desireSpeed`下降门控、目标相对最低值不超过0.1m/s的微小回升容忍、电机0.6秒观察期。
需求减速度仍取`clamp(速度误差/2, 0, 0.8)`，并沿用需求增长/减小速率；不抬高当前电机速度上限。

实测减速度比需求少超过0.12m/s²时，须由新的有效加速度估计连续确认0.3秒，才允许普通补刹积分。
确认后短缺降到0.05m/s²及以下退出，避免阈值附近反复切换；中断/无效估计重建确认。
0.3秒和退出0.05是本轮工程防抖初值，不是两份bag拟合出的车辆物理常数。
加速度仍为导航速度0.1秒差分加0.2秒低通，重复控制周期、同时间回调不会推进新确认。

积分仍`I += 正速度误差 × dt`，单位m，默认门槛0.1m、上限0.2m；
`/robot/control/brake_integral_threshold`仍按现有`getCached`读取，实际饱和上限为合法运行门槛的2倍。
积分只决定普通补刹是否启动，不直接换算制动百分比。等待响应/卸压期间不继续累积。

### 未确认与失效分别处理

| 状态 | D挡输出与处理 |
|---|---|
| 普通小请求2秒未响应，或普通正请求的响应长期消失 | 标为`unconfirmed`，撤销普通液压请求，保持`pending`与零驱动；不能凭零反馈或经过3秒猜测释放 |
| 已有普通在途请求，误差>0.5m/s且实测减速度比`min(0.8, error/2)`少>0.2m/s²，独立新估计连续1秒 | 未确认时转100%故障；普通已撤销/退出调节时，给最后正请求至少1.8秒执行观察，再在完成旧周期前判故障，迟到短反馈不能洗掉失败证据 |
| 规划回升取消普通请求，但仍明显超速且完全不减速 | 在途执行失败监视继续；取消积分不取消此保护。没有在途请求时不会凭单纯超速发起本轮补刹 |
| 强请求2秒无响应且车辆仍移动，或反馈不可信 | 故障100%。新强请求不继承旧普通超时；反复强请求不能延迟最早强请求超时 |
| 强请求无响应，但导航/CAN新鲜、实际停稳≤0.03m/s | 保留原停车保持量、标未确认并禁油，不单因反馈0额外锁100；新任务不能直接解除执行未知状态 |
| 已实际响应、撤销后仍持续非零反馈 | 从撤销时刻和首次实际响应时刻中较晚者起，3秒仍不释放则故障；未知迟到阶段本身不按“已响应未释放”判 |
| 15%主动调节仍不足 | 保留最后加量1.8秒观察，再由新的有效加速度估计确认持续不足1秒，才转故障；缓存估计不能补足确认时间 |
| 液压过程中短暂反馈过期 | 维持上一实际发布量和其普通/强制来源，禁止驱动；本周期新强停车不得被降级。持续过期0.5秒仍故障 |
| 原规划safety、CAN急停及现有独立安全停车 | 原优先级保持；紧急100%不等待普通观察、积分、0.3秒确认或15%上限 |

`unconfirmed`与`fault`均不允许自动猜测恢复。两者保留既有人工解除条件：
**手动D挡、导航停稳≤0.03m/s、CAN/导航新鲜且实际零制动连续确认至少0.5秒**。
手动N不能替代这个人工解除步骤；但已实际观察到响应并确认释放的正常周期，可以按释放条件自然结束。
自动停稳、任务更换、切R再切D和一条零反馈，都不能解除真正的故障锁定。
新增未确认诊断限频1Hz，区分`response unconfirmed`与`fault`。

## 保留的参数与边界

3%普通初始请求、每0.5秒最多+1/-2个百分点、15%普通上限、1.7秒撤刹预测、
0.15秒新鲜零反馈确认、最后正请求后1.8秒驱动保护均保留；本轮没有把反馈归零改成即时给油。
D×13.5、当前车速+0.5、5%低速保底、曲率公式/当前车速×4秒预瞄/抗噪、横向与R控制保持。
没有新增常态起步上升斜坡。

这两份bag没有独立持续3%试验，最高速度约3.75m/s。最低可靠接入指令、15%能力、
不同工况撤刹后的总剩余降速量与最坏迟到上界仍须标定；1.7/1.8秒不被宣称为已验证最坏界。
因此没有用8个电机/液压混合事件构造“百分比→净减速度”的逆表，也没有宣称5m/s紧急制动已验收。
零油门仍会回馈减速，互锁等待可能欠速；本轮先消除误分类并减少不必要介入，不能保证任意目标突降都舒适。

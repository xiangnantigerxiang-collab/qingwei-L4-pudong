# 2026-09-20 闸机参考路径约束与历史清理

## 当前规则

只有`active && !gantry_open`且任一固定闸机点满足以下两项，才叠加最终`safety=1`：

1. 进货站`(96.14,-405.63)`或出货站`(91.13,-393.80)`到当前参考路径最近实际点的距离<2m。
2. 该点按当前参考路径点序位于自车前方，实际沿线里程差满足`0 < Δs < 4m`。

闸机匹配离散参考点；自车匹配最近线段投影。路径里程按相邻点实际长度累加，端部保留
自车在首/末段切向的投影里程，避免钳到端点造成距离少算。坐标使用消息的float32精度。
同位置、车后、恰好2m/4m、空/单点/全重复参考、非有限坐标及XY长度不匹配均不启用本项。

在位置条件不成立的最终发布周期清除`mGantryStop`；任务复位清空参考也走这条处理。
重新进入范围需新关闭消息；开闸/active=false立即清除输入。不缓存几何匹配结果。
只清理闸机状态，不清理其他模块的safety、计数、迟滞或任务状态；闸机仍只改最终安全标志，
不改目标速度/路径点/声光。发布后恢复原内部值，避免在退化路径和安全来源交接时残留。
同一有效范围内无新消息时仍保持最近状态，没有新增断流超时策略。

- `src/pnc/src/robot_path_plan/path_plan_comply.h`：声明位置判断方法，更新闸机缓存语义说明。
- `src/pnc/src/robot_path_plan/path_plan_output.inc`：位置判断、无效范围清缓存和最终输出叠加。

测试修改4个文件：`gantry_safety.cpp`、`perception_safety_integration.cpp`、
`startup_observation_integration.cpp`、`terminal_stop.cpp`。
文档更新规划/检测/测试README与workflow，本记录为新增文件。无业务源码新增或删除。
control、感知算法、检测器、消息、参数、CSV、CMake及launch保持原字节。

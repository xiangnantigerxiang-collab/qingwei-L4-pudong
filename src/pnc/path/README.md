# 路径 CSV 格式

更新：2026-09-20。本目录地图数据统一为四列 `x,y,heading,speed`，无文本表头。
x/y为原地图坐标（m），heading保持原北零顺时针角度（deg），speed为该点最高限速（m/s）。
默认speed为10，即36km/h；它只是上限，规划与任务/感知/停车等已有速度取较小值。
0限速有效，不自行赋值或清除safety。

```csv
96.14,-405.63,90,10
96.34,-405.63,90,0.5
```

## planning 自动校验并保存

`LoadPathFile()`每次装载实际任务/作业地图时校验全部数据行：

- 三列x/y/heading：补`,10`，并保存到该CSV原文件。
- 已有四列：保留原speed，不重复写文件。
- 历史多列：只保留前四列，不读取或解释额外字段的业务含义，并保存到原文件。
- 混合三/四/多列也逐行统一；保留前三列原文、已有第四列、BOM、空行、整行注释、
  LF/CRLF及原文件最后一行是否有换行。注释以`#`开始，不属于数据列数校验对象。
- 前四列必须为有限数值，speed非负；缺少x/y/heading、空字段、文本表头、
  非法数值等情况整段失败，不臆造几何，不保存部分转换结果。

只有整份数据有效才通过同目录临时文件、flush/fsync和rename替换原文件，保留权限位；
软链接保留链接本身并更新实际目标。若加载期间原文件被修改、无写权限或写入失败，
保留原文件、记录错误并返回空路径，任务拼接不沿用旧路线或跨过缺失段。
因此自动转换需要节点对地图文件及其目录有写权限；转换成功后再次加载没有写回开销。
校验/转换仅发生在地图装载时，不在10Hz速度判断中执行。

## 已删除功能与其他读取方

第五列变道标志已删除，PNC不再将CSV数据写入z_axis或传递该变道开关。
通用几何结构的z_axis仍服务于其他算法，与地图CSV输入无关。
`speed_limit.csv`及其5m圆形区域限速读取/缓存/应用已删除；旧文件即使被放回目录也不会生效。
第四列地图限速、闸机8m位置门控和其他safety来源继续独立生效。

`fence.csv`已移出 control 模块（不再由 control 读取或执行停车），保留作为围栏数据资产供其他监控或上游模块使用。
`pudong_air/{left1,left2,right}.csv`仍用于ultra_command区域，保留原几何，原读取器只取x/y。
simviewer的四列读取兼容保持。不要修改区域多边形或围栏坐标来适配格式。

planning按行驶路径最近点取地图限速，D/R均适用；连接段抽稀/样条继续保留被跨过区间的
最低限速。本次没有增加前方低限速区的提前制动距离。地图在任务装载时读取。部署应同步源码和CSV，重编robot后重启相关节点。

验证和同步范围见 [本轮验证](../tests/planning/csv_four_column_verification_20260920.md)。
